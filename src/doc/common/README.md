# Doxygen shared assets

Shared look and feel for both generated API sites (CSL and MARTY):

- `DoxygenLayout.xml`: page layout (navigation, sections).
- `header.html`, `footer.html`: page header and footer.
- `customdoxygen.css`, `style.css`, `style_extra.css`: styling.
- `Logo1.svg`: logo used in the header.

Referenced from the `Doxyfile.in` and `dox-config.in` templates in `../csl/` and `../marty/`.
