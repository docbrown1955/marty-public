# GRAFED resources

Images embedded in the GRAFED application through `app.qrc` (in `../gui/`).

- `images/`: particle and vertex icons, for example `Scalar.png`, `Fermion.png`, `Vector.png`,
  `Gluon.png`, `Gaugino.png`, `Gluino.png`, `Ghost.png`, `Majorana.png`, their anti-particle
  variants, plus toolbar icons (`add`, `select`, `grid`, `trash`, `reset`, `quit`, ...).
- `logo/`: the GRAFED logo in PNG and the black and white ICO files for the window icon.

Add an image here and list it in `app.qrc`. Otherwise it will not be found at run time.
