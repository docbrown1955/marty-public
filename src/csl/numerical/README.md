# CSL numerical

Numerical counterparts of CSL's symbolic functions.

- `mathFunctions.cpp`: numerical evaluation of elementary functions (exp, log, trigonometric,
  and so on).
- `numerical.cpp`: numerical support for evaluating CSL number types.

These are used by the generated numerical libraries, see `src/csl/library/` and
`src/csl/librarygenerator.cpp`.
