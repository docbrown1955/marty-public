# Documentation folder (manuals and API HTML)

- `csl/html/`: Doxygen-generated HTML API reference for CSL, one file per header and class.
- `marty/html/`: Doxygen-generated HTML API reference for MARTY.
- `marty-manual.pdf`: the MARTY user manual.
- `csl-manual.pdf`: the CSL manual.
- `tutorial.pdf`: the tutorial.
- `guhlrich_phd_thesis.pdf`: the PhD thesis of the main author (Grégoire Uhlrich).
- `talks/`: slides and posters presented at conferences (ICHEP, SUSY 2021, Pheno 2022, and
  others), plus a tutorial archive and a demo video.

The HTML is generated by the Doxygen targets in `src/doc/` (`doc-csl`, `doc-marty`). Regenerate
it rather than editing it by hand.
