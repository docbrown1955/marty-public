# Project website and documentation

`docs/` is the static website published at marty.in2p3.fr, plus the released manuals and
archives. Its HTML pages (`index.html`, `learn.html`, `download.html`, `gettingStarted.html`,
`publications.html`, `contact.html`) link to the sub-folders below.

| Folder | Content |
|--------|---------|
| `style/` | CSS for the website pages |
| `fonts/` | Montserrat web fonts |
| `images/` | Banners and logos used by the website |
| `code/` | Source archives of past MARTY releases (0.8 to 1.5, `.tar.xz` and `.zip`) and `gettingStarted.cpp` |
| `doc/` | Manuals (`marty-manual.pdf`, `csl-manual.pdf`, `tutorial.pdf`), the generated API HTML (`csl/html`, `marty/html`), and talks (`talks/`) |

The developer documentation written for the code is in [architecture/](architecture/README.md),
not in the website pages.
