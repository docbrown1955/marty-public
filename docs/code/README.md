# Release archives and getting-started code

- `MARTY-<version>.tar.xz` and `MARTY-<version>.zip`: source archives of past releases, from
  0.8 up to 1.5 (including 1.2beta, 1.2.1 and 1.21). They are kept for reproducing old
  calculations. Download the current version from the repository, not from here.
- `gettingStarted.cpp`: a copy of the getting-started example for the website tutorial. It is not
  identical to `examples/gettingStarted.cpp`, so check both before editing.

Do not edit the archives.
